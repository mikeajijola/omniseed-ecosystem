# Splunk Cloud provider candidate

This fixture-backed prototype maps Splunk Cloud Platform beneath canonical `observations`. SPL, indexes, sourcetypes, dashboards and SIEM vocabulary remain provider provenance. Search results are evidence and never grant reconciliation authority.

The contract separates ingest, search, audit and configuration authority and evaluates freshness, indexing delay, retention, redaction, encryption, component health and exact compliance environment. Promotion is blocked pending live test-stack evidence and confirmation of distinct ecosystem leverage.
