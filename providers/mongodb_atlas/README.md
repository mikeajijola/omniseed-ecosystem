# MongoDB Atlas provider candidate

This fixture-backed provider maps MongoDB Atlas beneath canonical `memory`. Document, collection, BSON, tier, search and sharding vocabulary remains implementation provenance. Commercial and Government deployment compliance scopes are distinct.

The adapter requires scoped authority, exact region/tier/project selection, authoritative readback, and independent KMS, audit, backup, private-network and cost assertions. Governed/current promotion is blocked until equivalent live non-production evidence is supplied.
