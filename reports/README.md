# Conformance reports

`latest.json` is generated by `npm run conformance` and is committed as the latest public evidence snapshot.

Historical reports may be published by CI under `reports/history/` or GitHub Pages. They are not committed by default.

The report separates machine-proven failures from warnings and invariants that still need semantic review. Freshness compares the exact governed subject revisions, Provider package digests and set, and invariant digest in the observed `subjectState` with a previously certified mainline report. The default certification is `reports/main/latest.json`; `--certified-report` selects another read-only certification source. Matching state is `current`, drift is `stale`, and missing, invalid, incomplete, or dirty state fails closed to `indeterminate`. Callers cannot assert the result. Candidate evidence requires a separate output and cannot replace canonical mainline evidence.
