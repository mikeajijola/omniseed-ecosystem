# Adding an invariant

1. Start with a principle that the invariant protects.
2. Give the invariant a new permanent ID.
3. State one condition that can be evaluated without changing its meaning.
4. Decide whether it is deterministic or semantic.
5. Name the repository owner and affected scope.
6. Add a failing fixture before implementing a deterministic rule.
7. Add clear evidence and remediation text.
8. Run the full conformance suite against all three repositories.

Do not turn a preference into a critical failure. Do not label a judgment deterministic merely because a script can search for words.
